Three-case FEM versus frozen-primary spatial comparison
======================================================

Selected cases: case_80 (best RMSE), case_178 (median RMSE), and case_31 (worst RMSE) among the 50 sealed final-test cases.
Each case contains all 400,360 elements; no element sampling was used.
The formal frozen primary model is mean_calibrated_consensus.

For every case, the FEM and prediction field files share the same ElementID/X/Y/Z/MaxPrincipalStress schema. Use identical camera settings and a common colour scale when comparing FEM with prediction. Use a common scale across all three cases only if cross-case stress magnitude is the intended comparison.

Recommended thesis use: median case in the main results; best and worst cases together in the model-capability and limitation discussion or appendix.
